# Recanto das Asas — atualização Android 0.2.3

Esta entrega acrescenta os atalhos fixos ao APK Android: Cadastrar, Aves, Casais, Financeiro e Menus, nos temas claro e escuro. Conserva a correção do menu da versão 0.2.2 e usa as operações existentes.

## Baixar e instalar

1. Na página desta entrega, abra **Assets → Source code (zip)** e extraia o ZIP.
2. Faça e guarde um backup completo no aplicativo atual.
3. Abra **Recanto-das-Asas-0.2.3-debug.apk** pelo aplicativo Arquivos no Android e escolha **Atualizar**.
4. Mantenha a instalação existente. Abra com a senha atual, confirme a versão 0.2.3 e teste os cinco atalhos.

O Windows e o servidor Tailscale podem continuar como estão. Esta atualização muda a apresentação do Android e preserva a identidade do aplicativo, a assinatura de avaliação, a base local e a sincronização.

O ZIP inclui o APK, código-fonte, instruções, resultados de testes e capturas de bases fictícias isoladas. A instalação física e o teclado do telefone ainda precisam ser confirmados no seu aparelho.
